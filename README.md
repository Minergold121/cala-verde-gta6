CALA VERDE is a sun-soaked 3D open-world crime game in a coastal city at golden hour: drive and steal cars, lose 5-star CVPD dispatch with roadblocks and the Air One helicopter, run 10 story jobs with Milo Ferreira and his crew, and smuggle across the sandbar causeway that only opens at low tide.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no network, no build step, everything runs from the files in `game/`.
